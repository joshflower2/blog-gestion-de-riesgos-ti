# Análisis y gestión de riesgos en TI

Blog de **Joshua Flores** sobre la evaluación y el tratamiento de riesgos en tecnología de la información. Incluye una matriz interactiva y un video en español sobre un caso ficticio de ransomware.

Abre `index.html` en tu navegador para leer el blog. Para reproducir el video con subtítulos, sirve los archivos mediante HTTP desde la raíz del repositorio.
